# Cuentas Claras

App sencilla para llevar tus cuentas personales o en pareja: movimientos, recibos y avisos de vencimiento, ahorro y patrimonio, e importación de extractos del banco (CSV y Excel).

**Ábrela aquí:** https://cgp-ops.github.io/cuentas-claras/

## Privacidad
- Tus datos se guardan **solo en tu móvil** (almacenamiento local del navegador). No hay servidores, cuentas ni analítica.
- Los extractos que importas se leen en el propio dispositivo; no se envía nada fuera.
- Funciona **sin conexión** una vez abierta la primera vez.
- Haz copias de seguridad desde *Ajustes › Exportar JSON*.

## Instalar en el móvil
- **iPhone (Safari):** abre el enlace, toca *Compartir* → *Añadir a pantalla de inicio*.
- **Android (Chrome):** abre el enlace, toca el menú ⋮ → *Instalar app* (o *Añadir a pantalla de inicio*).

Cuando haya una versión nueva, se carga sola al abrir la app con conexión (y si la tenías abierta verás «Hay una versión nueva · toca para actualizar»). Tus datos se conservan.
